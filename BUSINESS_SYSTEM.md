# Pink Leaf business system - file map

The organized structure so everything has a home. When Kat uploads something, it
goes to the matching area. Sensitive files (receipts, invoices with personal
details) stay on the private machine, NOT in this public repo; the repo holds the
ledgers and non-sensitive working docs.

## Where everything lives
| Area | What goes here | Files today |
|---|---|---|
| inventory | stock counts, mothers, reserved | SUPPLIER_TOTALS.md, MOTHER_PLANTS.md, CLIENT_RESERVED.md, ACCLIMATION_QUEUE.md |
| pricing | price list, competitor, cost/margin | PRICE_LIST_FINAL.md, PRICED_MASTER_LIST.md, COMPETITOR_PRICES.md, PLANNED_PRICE_LIST.md |
| suppliers | catalogs, supplier strategy, imports | SUPPLIER_DOCS_INDEX.md, SUPPLIER_STRATEGY.md, SUPPLIERS_CHINA_RESEARCH.md, MINHUI_CATALOG.md, MNG_TC_COMPARISON.md |
| purchases | orders-in, invoices, payments | PURCHASES_LEDGER.md (invoices themselves kept private) |
| customers | customer orders, fulfillment | orders/ORDERS.md |
| expenses | receipts ledger | expenses/RECEIPT_LEDGER.md (receipt images kept private) |
| content | cards, captions, calendar | social-posts/CAPTIONS.md, CARD_REGISTRY.md, content/CONTENT_CALENDAR_*.md |
| business-plan | the plan | (built on the clean computer from the above) |

## Privacy rule
This repo is PUBLIC. Never commit: customer surnames, home addresses, phone
numbers, receipt/invoice images, bank details. Those live on the private machine.
Ledgers here hold only non-identifying data (date, vendor, category, amount).
